## Modifications

Section 2(e) requires modified versions to be conspicuously marked. This directory contains one:

* **`spot_physics.urdf`** — a modified version of `model.urdf`. `<inertial>` (per-link masses,
  28.0 kg total) and `<collision>` (a box body, capsule leg segments) are added to all 13 links,
  because BD's URDF ships neither and a physics engine cannot stand the robot up without them.
  Visuals, joint origins, axes and joint limits are the original's, untouched. The added values
  come from threepp's `spot_deploy.build_spot`, so the file describes the plant threepp's Spot
  policies were trained against. Generated by
  `python/examples/spot/editor_deploy/make_spot_urdf.py` in the threepp repository, and marked as
  modified in its own header.

`model.urdf` and the meshes in `link_models/` are **unmodified**.
